# wordSlayer


Välkommen till wordslayer spelet. 

Här kan du spela med en eller flera vänner eller ovänner. 

Spelet går ut på att du ska hitta så långa ord som möjlight eftersom varje bokstav ger skada till motståndaren. 

Vi kommer att addera fler features efter gång. 

Samt hur man startar spelet.
